# 👥 Employee Management System

A responsive Employee Management System built with React and Tailwind CSS.

Live Preview: https://employeemanagementsystembisma.netlify.app/

This project was created as a **Week 3 Day 5 Capstone Project** to combine React concepts such as project architecture, state management, reusable components, custom hooks, CRUD operations, search, and filtering.

---

## 🚀 Features

- ➕ Add new employees
- ✏️ Edit existing employees
- 🗑️ Delete employees
- 🔍 Search employees by name
- 🔎 Filter employees by department
- 💾 Persistent data using Local Storage
- 📊 Total and visible employee statistics
- 📱 Responsive design
- ♻️ Reusable React components
- 🎨 Tailwind CSS styling

---

## 🛠️ Tech Stack


- React
- Vite
- Tailwind CSS
- JavaScript
- Local Storage
